# Elemental Genesis

**A 3D Mobile-Based Civilization-Building Educational Game**  
*Thesis project for Senior High School STEM Chemistry learning*

## About the Project

**Elemental Genesis** is an Android civilization-building game developed as a thesis project. Players develop a civilization by constructing buildings, managing resources, researching chemical elements, and exploring how materials relate to elements and compounds.

The game connects civilization progression and resource management with selected Chemistry concepts to provide an interactive learning experience for **Senior High School STEM students**.

## Thesis Purpose

This research project explores the use of a mobile civilization-building game as a supplementary tool for learning Chemistry, particularly:

- Chemical elements and their properties
- Compound formation and the elements that make up materials
- Applying Chemistry concepts through interactive research, construction, and resource-management activities

The Android build is being distributed for **thesis testing and evaluation**. Participant feedback will help assess the game's usability, functionality, engagement, and potential educational value. The project does not claim that learning improvements have already been established.

## Game Features

- **Civilization building:** Build and manage structures that support a growing settlement.
- **Resource management:** Balance resources and infrastructure needed by the civilization.
- **Element research:** Explore and unlock chemical elements as part of civilization progression.
- **Material construction and deconstruction:** Interact with in-game materials associated with elemental composition.
- **Mobile gameplay:** Play on an Android device.

*Features and content may change during development.*

## Download and Install (Android)

1. Open the repository's **[Releases](../../releases)** page.
2. Choose the appropriate release and expand **Assets** if needed.
3. Download the `.apk` file to your Android device.
4. Open the downloaded APK and follow Android's installation prompts. If asked, allow your browser or file manager to install apps from this source.
5. Launch **Elemental Genesis** after installation.

> **Note:** This is a test build distributed outside Google Play. Android may display an installation warning. Download only from the project's official release page. Device compatibility may vary.
